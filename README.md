# Лабораторная работа №1 — ИУ3-33Б

Студент: Hosseinpoor Ali  
Группа: ИУ3-33Б

Реализованы задачи 1–12 (12 баллов при оценке по 1 баллу за каждую задачу).
Каждая задача находится в отдельном package `ru.bmstu.lab01.task_<номер>` и имеет отдельный `Main.java`.

## Структура
- `src/main/java/ru/bmstu/lab01/task_1/Main.java` — задача 1
- ...
- `src/main/java/ru/bmstu/lab01/task_12/Main.java` — задача 12
- `report.md` — краткое описание решений и асимптотики
- `pom.xml` — Maven-конфигурация

## Ввод
Во всех задачах используется стандартный ввод. Первым числом читается `n`, затем `n` элементов массива. Если в условии требуется дополнительное число (`x`, `k` или `s`), оно читается после массива.

## Сборка
Требуется JDK 25, как указано в конфигурации проекта.

Из корня проекта:
```bash
mvn test
mvn package
```

Отдельный запуск, например для задачи 1:
```bash
java -cp target/classes ru.bmstu.lab01.task_1.Main
```
После запуска введи данные в консоль.
